# Acara 21 — Dokumentasi Endpoint

Melanjutkan Acara20. Dokumen [API_DOCUMENTATION.md](docs/API_DOCUMENTATION.md)
menyajikan peta resource ke controller, request/response, autentikasi, dan
status HTTP seluruh endpoint.

## Menjalankan

1. Aktifkan Apache dan MySQL pada Laragon.
2. Import `si-akademik/db_workshop.sql` melalui phpMyAdmin.
3. Buka `http://localhost/bkpm/Acara21/si-akademik/public`.
4. Import `Acara21.postman_collection.json` dan environment Local di Postman.
5. Gunakan collection secara berurutan; request login mengisi variabel token.

## Praktik Mandiri

Tabel ringkasan semua endpoint beserta Controller sudah diletakkan di bagian
awal dokumentasi API. Request Postman dilengkapi deskripsi endpoint untuk
membantu pembuatan dokumentasi Collection Postman.
